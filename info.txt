Веб-сторінка побудована з використанням сучасних методів розмітки CSS Flexbox і CSS Grid. Усі ілюстрації, включаючи логотип, згенеровані за допомогою ChatGPT. Для забезпечення адаптивності використовуються відносні одиниці вимірювання у поєднанні з медіа-запитами. Для мобільних екранів реалізовано бургер-меню на CSS і JS.
